The AsterixDB APIs require HTTP basic auth.
{{- if .Values.auth.existingSecret }}
Credentials are those in the Secret {{ .Values.auth.existingSecret }}.
{{- else }}
Username: {{ .Values.auth.username }}
Password: kubectl get secret --namespace {{ .Release.Namespace }} {{ include "asterixdb.authSecretName" . }} -o jsonpath='{.data.password}' | base64 -d
{{- end }}

Query service:
  kubectl port-forward --namespace {{ .Release.Namespace }} {{ .Release.Name }}-cc-0 19002
  curl -u <username>:<password> http://localhost:19002/query/service --data-urlencode 'statement=SELECT 1;'
